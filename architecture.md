# Project Architecture: De-Brill Learn App

## Overview
De-Brill Learn App is a cross-platform educational application built with React and Capacitor. It provides a structured learning environment for children, with dedicated portals for teachers and parents, and a robust admin management system.

---

## Tech Stack
- **Frontend Framework**: [React 19](https://react.dev/) (via [Vite](https://vitejs.dev/))
- **Mobile Bridge**: [Capacitor](https://capacitorjs.com/) (Targeting Android/iOS)
- **Styling**: [Tailwind CSS 4](https://tailwindcss.com/)
- **Backend-as-a-Service**: [Supabase](https://supabase.com/) (Authentication, Database, Storage)
- **Routing**: [React Router Dom v7](https://reactrouter.com/)
- **Animations**: [Motion](https://motion.dev/) (Framer Motion)
- **Icons**: [Lucide React](https://lucide.dev/)
- **AI Integration**: Anthropic SDK (for content/interaction)

---

## Directory Structure

### Root Directory
- `/src`: Main application source code.
- `/android`: Native Android project files generated by Capacitor.
- `/native`: Additional native code/assets.
- `/supabase`: Supabase configuration, migrations, and edge functions.
- `/api`: Backend API logic or serverless functions.
- `/public`: Static assets (logos, manifest, etc.).
- `/Book covers` & `/Speech Organs`: specialized asset directories for educational content.

### Source Code (`/src`)
- `App.tsx`: Central routing hub and application shell.
- `main.tsx`: Application entry point.
- `index.css`: Global styles and Tailwind configuration.

#### 📂 `screens/`
Organized by "Flows" to represent user journeys:
- **FlowA (Onboarding)**: Splash screen, Welcome carousel, Login, Registration, Role selection, Profile setup.
- **FlowB (Learning)**: Home (Child/Student), Library, Book details, Units, and the Lesson cycle (Warm-up -> Words -> Story -> Activities -> Practice -> Comprehension -> Completion).
- **FlowC (Subscription)**: Pricing plans and payment processing.
- **FlowD (Gamification)**: Practice menu and games (Sound Safari, Blend Bridge).
- **FlowE (Tracking)**: Progress dashboards and achievement galleries.
- **FlowF (Account)**: Student profile, Notifications, and comprehensive Settings.
- **FlowG (Teacher)**: Teacher dashboard, Class management, and Web portal.
- **FlowH (Parent)**: Parent dashboard and child-specific progress tracking.

#### 📂 `features/`
- **admin/**: A self-contained module for platform administration (Dashboard, User management, Content management, Analytics).

#### 📂 `components/`
- Reusable UI elements: `Button`, `Layout`, `BottomNav`, `BookCover`.

#### 📂 `lib/`
- `AuthContext.tsx`: Global authentication state management.
- `supabase.ts`: Client initialization.
- `api.ts`: Shared data fetching logic.
- `speech.ts`: Specialized logic for speech recognition or synthesis.

---

## Key Design Patterns
1. **Role-Based Access Control (RBAC)**: Distinct interfaces for Students, Teachers, Parents, and Admins.
2. **Mobile-First Design**: The core UI is constrained to a mobile viewport (`390px` width) for consistency across devices.
3. **Modular Flow Structure**: UI and logic are grouped by user journey phases (Flows A-H).
4. **Error Boundary Protection**: Root-level error handling to ensure app stability.
5. **Context-Driven State**: Authentication and user metadata are shared via React Context.

## Build & Development
- **Dev Server**: `npm run dev` (Vite)
- **Build**: `npm run build`
- **Mobile Sync**: Capacitor commands are used to sync the web build to the `android` platform.
